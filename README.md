# Heart
## Animated Heart
This is a small web project that displays an animated heart with additional background hearts, created using HTML and CSS.

## Features
- The main heart pulses using CSS animation.
- Background hearts move and change size and color.
- Uses clip-path to create a heart shape.
- Responsive design works on any screen using Flexbox.
